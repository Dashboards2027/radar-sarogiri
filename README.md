# Radar Sarogiri

Radar de tendencias para SAROGIRI. Junta lo que está en tendencia en X, Google Trends, Reddit y TikTok (Argentina y mundo), lo agrupa, le asigna etapa y categoría, y lo muestra en un dashboard.

- Web (se actualiza sola cada hora): https://dashboards2027.github.io/radar-sarogiri/
- En tu compu: doble clic en `Abrir Radar.bat` (requiere Python y `pip install -r requirements.txt` + `python -m playwright install chromium`).

Todo gratis: sin APIs pagas.
